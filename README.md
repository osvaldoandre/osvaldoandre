# 🚀 Projetos

## 🔐 Sistema de Controlo de Acesso em Tempo Real

Sistema desenvolvido para controlar a entrada e saída de alunos através de identificação por RFID.

O projeto combina programação, eletrónica e comunicação GSM para criar um sistema de controlo de acesso funcional.

### Tecnologias

`C` `Arduino` `RFID` `SIM800L` `LCD` `Servo Motor`
